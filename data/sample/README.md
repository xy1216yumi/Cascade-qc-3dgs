# sample 目录说明

把要检查的渲染图放在这里，命名 `image_01.png`、`image_02.png` …（支持 png/jpg/jpeg）。

## 渲染图怎么生成（建议）

1. 用你们 3D pipeline 对场景做一帧渲染（或 3DGS 任意视角渲染）；
2. 对同一帧跑 SAM2 得到实例 mask；
3. 用 PIL 把每个 mask 用不同颜色叠加到渲染图上（半透明即可）；
4. 在每个 mask 的中心（或左上角）写数字编号；
5. 保存为 png。

要点：**编号必须清晰可见**，因为 Kimi K3 要引用"实例 N"；
建议优先挑选有堆叠/嵌套/接触物体的场景（这正是解嵌论文的 motivation 素材）。
