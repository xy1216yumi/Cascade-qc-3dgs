# 上云操作手册 v2（SmoothCloud GPU 实例）

## ⚠️ 关键坑位：实例 GPU 可能是 RTX 5090（sm_120）

SmoothCloud 的"高性能推理卡"实为 **RTX 5090（Blackwell, sm_120）**，经 HAMI vGPU 虚拟化
（`nvidia-smi` 显示 100% 利用率/0MiB 是虚拟化假象，不代表被占用）。
sm_120 需要 **CUDA ≥ 12.8**：

- torch ≤ 2.6（cu124 及以下）**无法运行**（报 `no kernel image is available`）；
- gsplat 官方预编译 wheel 最新只有 pt24cu124（cp310），对 5090 **全部不可用**；
- 唯一可行路线：**torch 2.8（PyPI 默认 cu128）+ pip 版 nvcc 12.8 + gsplat 源码 JIT 编译**。

## 一键环境搭建（`cloud/setup_env2.sh`，已含全部坑位修复）

前提：实例有 python3 + pip。脚本自动完成：

1. uv 安装 + Python 3.10 venv（`venv/`）
2. torch 2.8.0（清华 PyPI 镜像，cu128 支持 sm_120）+ CUDA 算子自测
3. pip 版 `nvidia-cuda-nvcc-cu12==12.8.93` + cccl，组装 `CUDA_HOME=/root/cuda-12.8`
4. gsplat 1.5.3 源码安装（`--no-build-isolation`），首次渲染时 JIT 编译（约 5–15 分钟，仅一次）
5. 光栅化自测（`RASTER_OK` 即成功）

```bash
# 本地上传（Windows Git Bash）
scp -i root_public_key.txt cloud/setup_env2.sh root@<实例IP>:/root/workspace/
scp -i root_public_key.txt cloud/cloud_3dgs_000048.zip root@<实例IP>:/root/workspace/
scp -i root_public_key.txt cloud/cloud_scenes_049_059.zip root@<实例IP>:/root/workspace/   # 可选：全 12 场景

# 云端执行
ssh -i root_public_key.txt root@<实例IP>
cd /root/workspace
nohup bash setup_env2.sh > setup2.log 2>&1 &   # 约 1–1.5 小时（主要是 torch 下载）
tail -f setup2.log
```

## 训练

```bash
cd /root/workspace
# 数据解压（zip 内不含顶层 cloud_data 时注意：scenes 包解压后需 mv 进 cloud_data/）
python3 -m zipfile -e cloud_3dgs_000048.zip .

# 单场景训练（75 帧，3 万深度初始化点，约 10–30 分钟）
nohup venv/bin/python train_gsplat.py --data_dir cloud_data/000048 \
    --max_steps 7000 --out output/000048 > train.log 2>&1 &
tail -f train.log

# 全场景批训练
for s in cloud_data/0000*/; do
  venv/bin/python train_gsplat.py --data_dir $s --max_steps 7000 --out output/$(basename $s)
done
```

## 网络注意事项（国内实例）

| 资源 | 可用源 |
|---|---|
| pip 包 | 清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| download.pytorch.org | **会停滞**，勿用 |
| github.com | **不通**（gsplat wheel 下载会超时），需本地下载后 scp 中转 |
| uv 超时 | `export UV_HTTP_TIMEOUT=600`（默认 30s 太短） |

## 省钱提醒

- 训练完**立刻**把 `output/` 下载回本地 `results/render_output/`，然后关机（关机不计费，数据保留 7 天）
- `ps aux | grep <关键词>` 排查残留进程时注意：pkill 的模式会匹配到自己所在的 `bash -c` 命令行，
  用 `pgrep -f "setup_en[v]"` 这种写法避免误杀自身
